# The Weight of a Flake

The line's goal remains unchanged. Gathering 10 reported no broken Line 4
command. This contribution adds the standalone standard-library
[offline EIP-712 integer reviewer](tools/integer-review/README.md). It exposes
exact integer values, encoding words, signed ranges, numeric-literal risks and
hypothetical binary64 rounding, without changing signed data or calculating
token units. It reuses the unchanged ancestor encoder and historical ZTO
evidence; `provenance.json` pins those copies. No dependency was installed.

The historical ZTO example reproduces its exact digest. Converting its amount
to binary64 would lose 1,979,176 raw units. A second fixture demonstrates the
same quantity written as a numeric literal: exact Python digest equality still
holds, while the tool flags the representation for JavaScript consumers.
